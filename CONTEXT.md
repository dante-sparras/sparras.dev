# sparras.dev

Dante Sparrås's personal site and portfolio: a single homepage presenting his profile, work and writing.

## Language

### Pointer effects

**Pointer effect**:
A visual response on an element that tracks the visitor's pointer while it is over the element and settles back to rest once it leaves.
_Avoid_: hover effect, animation

**Hover lens**:
The soft circular window on the banner that reveals the alternate black-hole image under the pointer, slightly magnified.
_Avoid_: reveal, magnifier, spotlight

**RGB split**:
A chromatic offset in which an element's red and blue channels pull apart along the line from its center toward the pointer; used on the profile avatar and skill tiles.
_Avoid_: chromatic aberration, glitch, RGB shift
